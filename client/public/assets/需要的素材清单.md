# UI 素材清单（待提供）

放置路径：`client/public/assets/`
文件名必须严格一致，图给到位即自动替换占位，**无需改代码**。

| 文件名 | 用途 | 建议规格 |
|---|---|---|
| `logo.png` | 登录页 + 主菜单 标题 Logo | ~480×160，透明 PNG，暖金色调 |
| `bear-avatar.png` | 小熊头像（主菜单） | ~120×120，透明底 |
| `rabbit-avatar.png` | 小兔头像（主菜单） | ~120×120，透明底 |
| `bg.jpg` | 背景氛围图（**可选**） | 1920×1080，暗色调、可模糊，缺失则用渐变回退 |

除此之外，UI 所有按钮 / 面板 / 胶囊都是代码绘制的（CSS + Phaser 图形），**不需要图片**。

游戏内角色与场景目前是几何图形 + 占位剪影（`ph_bear` / `ph_rabbit`），若后续要换成美术贴图请另提。
